## Architecture Notes

The project follows the "arnold pattern":
- Relational for analytics (if needed)
- Graph for relationships (NetworkX + JSONL)
- Flat files for portability (no database server)

Authority model prevents AI from writing "authoritative" - everything starts as "proposed" requiring human approval.

## Implementation Details

### Cross-Project Installation
Used importlib.resources to bundle templates and skill file in package:
- `src/trace_core/resources/__init__.py` provides get_template(), get_skill_file(), list_templates()
- Resources packaged via pyproject.toml configuration
- `trace init` loads from installed package, not source tree

### Auto-Detection Logic
Three-tier project type detection:
1. **Systems Engineering**: Checks for docs/requirements, docs/architecture, docs/decisions
2. **Agile**: Checks for tests/ and src/ directories
3. **Lightweight**: Default fallback

### Import Mapping
Python parser extracts both `import x` and `from x import y`:
- Handles module paths like `trace_core.models`
- Maps to file paths using project conventions
- Filters external libraries (os, sys, json, etc.)

### Error Fixes During Implementation
1. Template pattern ordering: Put specific patterns before generic ones
2. Import parsing: Added module.name extraction for "from x import y" syntax
